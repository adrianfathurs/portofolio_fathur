# Personal Portfolio Website

## 👋 About This Project

This repository contains the source code and documentation for my **personal portfolio website**. The website is designed to showcase my profile, skills, experiences, and projects as a **Software Engineer / Front End Developer**.

The design direction follows a **futuristic, simple, and interactive** theme with clean UI, smooth transitions, and responsive layouts.

---

## 🚀 Tech Stack

* **Node.js & npm** – dependency management
* **React JS** – component-based UI development
* **Tailwind CSS** – utility-first styling
* **GitHub Pages** – deployment

---

## 📁 Project Principles

1. Built using **npm-based workflow**
2. **React + Tailwind CSS** only (no heavy UI frameworks)
3. **Deployed on GitHub Pages**
4. Any code exceeding **100 lines must be refactored** into reusable components or helper functions
5. UI theme: **Futuristic • Minimal • Interactive**
6. Content is derived from my **professional CV & experiences**
7. Responsive in mobile device too.
