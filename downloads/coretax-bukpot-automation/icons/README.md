# Extension Icons

Icon files untuk Chrome Extension.

## Required Sizes

- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store, installation dialog)

## Quick Setup

### Option 1: Use Default Icons

Copy the default icons below (save as PNG files):

#### Icon Design Ideas:
- **Letter C** (Coretax) with download arrow
- **Document icon** with down arrow
- **Tax document** symbol
- **Simple download** icon

### Option 2: Generate Icons

Use online tools:
- https://www.favicon-generator.org/
- https://favicon.io/
- https://realfavicongenerator.net/

### Option 3: Create Custom Icons

Design tools:
- Figma (free, online)
- Canva (free templates)
- Adobe Illustrator / Photoshop

## Color Scheme

Suggested colors for Coretax theme:
- Primary: Blue (#2563eb)
- Accent: Green (#22c55e) - for success
- Background: White

## Current Setup

Anda bisa:

1. **Use any icon** - Copy any 16/48/128 PNG files to this folder
2. **Create simple icons** - Use online generator
3. **Skip for now** - Extension will still work without custom icons

## Temporary Solution

Copy any PNG images to this folder and rename them:
- Copy any small PNG → `icon16.png`
- Copy any medium PNG → `icon48.png`
- Copy any large PNG → `icon128.png`
