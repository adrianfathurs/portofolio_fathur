Coretax Automation - Icon Generator

Cara Menggunakan:

  1. Klik tombol "Generate Icons" di bawah
  2. Klik kanan pada setiap icon → "Save image as..."
  3. Simpan dengan nama:
    • Small → icon16.png
    • Medium → icon48.png
    • Large → icon128.png
  4. Simpan di folder extension/icons/
