# Coretax Tools Download

This folder contains automation tools for working with Coretax (Indonesian tax system).

## Available Tools

### 1. Coretax Bukpot Automation (Chrome Extension)

**Location:** `coretax-bukpot-automation/`

Chrome extension for bulk download bukti potong (tax deduction proofs) from Coretax.

**Features:**
- Automates bulk download of hundreds of documents
- Real-time progress tracking
- Activity logs
- Configurable delays and auto-scroll

**How to Install:**
1. Open Chrome and go to `chrome://extensions`
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked"
4. Select the `coretax-bukpot-automation` folder
5. Pin the extension to your toolbar for easy access

**For detailed instructions, see:** `coretax-bukpot-automation/INSTALL.md`

---

### 2. Coretax Bukpot PDF to Excel (Web Tool)

**Link:** https://adrianfathurs.github.io/coretax_bukpot_pdf_to_excel/

Web-based tool to convert tax deduction proofs from PDF to Excel format.

**Features:**
- Simple upload and conversion
- No installation required
- Saves hours of manual data entry
